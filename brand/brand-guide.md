# 织序 WeaveOrder · 品牌手册

> 版本 v1.0 · 2026-11-13 · 设计：巧匠（产品设计 & 增长）
> 本文是 logo、口号、色彩、字体与官网的统一口径。凡与本文冲突的物料，以本文为准。

---

## 1. 品牌内核

**产品**：织序（WeaveOrder），纺织贸易的智能体原生业务操作系统。
**定位**：不是「带 AI 功能的纺织 ERP」，而是「智能体干活、人只做决定」的业务系统。
**名字**：「织」是行业（经纬、样布、织标），「序」是秩序与流程；合起来是「把生意织成有序的单」。

一句话解释品牌要传达的三件事：

1. **智能体是操作者**：找样、报价、寄样跟进、对账都由智能体完成。
2. **人是审批者**：只在一张卡上批准、驳回或改一处。
3. **可信高于聪明**：确定性内核、只追加审计、金额整数分。智能体能干活，但改不了账。

## 2. 口号

**主口号（品牌口号）**

> ## 你说生意，系统做单。

四个字一顿，老板一听就懂：他只管说，剩下的单子系统去做。官网标题、名片背面、展会背板、产品开机页都用这一句。

**辅句（解释口号，用于副标题）**

> 报价、寄样、跟单、对账，智能体做完，你只点头。

**备选（按场景）**

| 场景 | 文案 | 说明 |
| ---- | ---- | ---- |
| 电梯里 15 秒 | 人只做决定，其余交给织序。 | 强调人的角色变化 |
| 面向业务员 | 客户一句话，10 分钟出报价。 | 具体收益，最容易被一线转发 |
| 面向老板 | 人走，客户不走。 | 直击行业最痛的一条 |
| 展会 / 海报 | 让每一单自己走完。 | 有画面感，适合大字 |
| 英文 | Speak the deal. Weave the order. | Product Hunt / 海外站 |

**用法规则**

- 主口号永远完整出现，句子中间不加标点修饰，不改写成「让系统帮你做单」这类弱化版本。
- 与产品名同现时写作「织序：你说生意，系统做单。」不写成「织序，你说生意，系统做单。」。
- 英文只做辅助，不与中文口号并排抢注意力。

## 3. Logo

### 3.1 概念：一枚织标

Logo 不是抽象的科技图形，而是一枚**织标（woven label）**：衣服后领上那块缝着品牌的小布标。

- 外形取织标的圆角方牌，四周一圈**虚线针脚**，说明它是缝上去的。
- 牌面是一个「**织**」字，用宋体（Noto Serif CJK SC Bold）的骨架，笔画带织物的重量感。
- 织标是纺织业最日常的「身份与批准」符号：**贴上去，就代表这家公司认了这一件货**。这与产品的核心动作「审批」是同一件事。

于是这个标记同时说了三句话：这是纺织行业、这是一个品牌标识、这是一个「被认可」的动作。

### 3.2 构成与安全边距

- 基础网格 64 × 64，圆角半径 14，内缩针脚 4.3，针脚 1.35 虚线（2.6 / 2.3）。
- 字高 34.5，视觉居中（按墨迹包围盒居中，不按字身框）。
- **安全边距**：四周至少留出 `1/4 标记高度` 的空白；横版组合中，标记与文字的间距为 `0.125 标记高度`。
- **最小尺寸**：带针脚的完整标记不小于 32 px（印刷 12 mm）；无针脚单色版不小于 20 px（印刷 8 mm）。再小只使用应用图标，不再放大字形细节。

### 3.3 版本

| 文件 | 用途 |
| ---- | ---- |
| `logo-mark.svg` | 主标记（墨底米白字 + 针脚），浅色背景 |
| `logo-mark-inverse.svg` | 反白标记（米白底墨字），深色背景 |
| `logo-mark-mono.svg` | 单色标记，无针脚，用于小尺寸、单色印刷 |
| `logo-mark-mono-inverse.svg` | 单色反白（镂空），可叠在任意深色上 |
| `logo-horizontal.svg` | 横版组合：标记 + 织序 + WEAVE ORDER |
| `logo-horizontal-inverse.svg` | 横版反白 |
| `logo-wordmark.svg` | 纯字标（无标记），用于窄条、页脚 |
| `logo-wordmark-inverse.svg` | 纯字标反白 |
| `favicon.svg` | 浏览器图标（单色版） |
| `icons/icon-180/192/512.png` | iOS / PWA / 应用图标 |

文字部分已转为轮廓路径，不依赖字体文件，可在任意环境无损打开。

### 3.4 不要这样做

- 不要给标记加渐变、发光、投影或描边。
- 不要把针脚改成实线，也不要把针脚加粗到抢字。
- 不要拉伸、旋转、倾斜，不要单独使用一个偏旁或裁掉针脚。
- 不要把标记放在高饱和底色（红、绿、蓝）上；深色底请用反白版。
- 不要在针脚与字之间再塞图形或标语。

## 4. 色彩

品牌色来自织物与染整，不用科技蓝紫渐变。

| Token | 值 | 用途 |
| ----- | -- | ---- |
| `--ink` | `#14202B` | 主文字、主按钮、深色区底色 |
| `--ink-700` | `#2B3B4A` | 次级文字 |
| `--ink-400` | `#7A8896` | 辅助信息、占位 |
| `--paper` | `#F7F4EE` | 页面底色（米白，像样布卡） |
| `--paper-deep` | `#EFE9DF` | 分区底色 |
| `--surface` | `#FFFFFF` | 卡片 |
| `--indigo` | `#1F4E79` | 品牌主色、链接、选中、智能体身份 |
| `--indigo-100` | `#E6EEF5` | 信息底 |
| `--vermilion` | `#C0492F` | 唯一强调色：人、审批、关键一笔 |
| `--moss` | `#3F6B4F` | 成功、已批准 |
| `--amber` | `#B7791F` | 待补、风险提示 |
| `--line` | `#E3DED4` | 分隔线、草稿虚线 |

**比例**：米白 70%，墨 20%，靛蓝 8%，朱砂 2%。
朱砂是全站唯一的强调色，一屏只出现一次主视觉强调；多了就不再是「人的一笔」，而变成装饰。

## 5. 字体

| 用途 | 字体 | 回退 |
| ---- | ---- | ---- |
| 标题 / 品牌字 | Noto Serif SC Bold（思源宋体） | Noto Serif CJK SC、Songti SC、SimSun、Georgia |
| 正文 / UI | Inter | Noto Sans SC、PingFang SC、Microsoft YaHei、system-ui |
| 数字 / 金额 / 日志 | JetBrains Mono | ui-monospace、SFMono、Consolas |

- 中文标题用宋体是刻意的：布行的招牌、样布卡、老账本都是宋楷骨架，比黑体更可信。
- 金额与编号全部等宽数字（`font-variant-numeric: tabular-nums`），右对齐。
- 字号阶：12 / 13 / 14 / 16 / 20 / 24 / 32 / 44 / 64 / 78。行高：正文 1.65 到 1.85，标题 1.18 到 1.24。
- 标题字距 `-0.01em` 到 `-0.02em`，正文 0；英文小标签字距 `0.18em` 到 `0.26em`（全大写）。

## 6. 图形语言

1. **经纬纹理**：1 px 网格、透明度 3% 到 5%，只出现在大色块边缘并做渐隐，用来暗示布面，不做整页贴图。
2. **虚线即草稿**：虚线边框表示「未经人确认」，实线表示「已生效」。这是产品里最重要的视觉规则，官网上也沿用（审批卡默认虚线）。
3. **针脚**：品牌标记的针脚是唯一的装饰性线条；其他分隔一律用 1 px 实线。
4. **数字可点开**：任何金额、比例旁边都能给出来源；没有出处的数字不上台面。
5. **朱砂一笔**：批准、盖章、关键 CTA 用朱砂；不要用朱砂做普通按钮。

---

## 7. 语气

- 说人话，用行业词：单、样、色号、交期、账期、柜。不用「赋能」「闭环」「数智化」。
- 句子短，动词在前。「客户一句话，10 分钟出报价。」
- 讲结果，不讲模型。「智能体做完，你只点头」，不说「基于大语言模型」。
- 承认边界。「它改不了账」「金额由内核算」，这种克制比吹能力更可信。
- 不承诺没验证的数字；没有试点数据时只写机制，不写百分比。
