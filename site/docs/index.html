最常被问到的十个问题

智能体会不会自己把价格发出去？

不会。智能体的产出永远是草稿，必须由人点「批准」才生效。金额改幅超过 5% 或 1 万元会自动升级给主管；低于成本底线直接拦下。看审批规则

现有的 Excel 客户表和样品表怎么导进来？

直接把文件拖进导入页。系统逐行检查，有一行不合格就整批不入库，并告诉你哪一行哪一列不对。改完再传即可。看导入格式

业务员只能看到自己的客户吗？

默认是。销售角色的数据范围是「本人」，主管是「本组」，老板是「全公司」。范围由管理员设置，调岗后仍能还原当时的权限。看角色表

客户要登录才能看报价吗？

不用。你把报价链接发到微信，客户点开就能看，能留言、能接受，不需要注册。链接可以设置有效期与访问密码。看报价分享

支持哪些打印机？

Zebra、TSC、佳博等主流标签机（ZPL / TSPL），以及针式打印机打发货单。装桌面版后打开打印代理，在设置里选机型即可。看机型清单

数据放在哪里？会不会被拿去训练模型？

数据存在国内云服务器，按公司隔离。模型调用只传当次任务需要的内容，不用于训练，也不会跨公司共享。看安全说明

怎么开发票？

付款后在「组织与设置 → 账单」里填开票信息，3 个工作日内开出电子发票，发到你留的邮箱。支持增值税普通发票和专用发票。看开票步骤

人离职了，客户会跟着走吗？

不会。客户属于公司，不属于个人。交接时把客户一次性转给接手人，历史报价、寄样记录、沟通偏好一起过去，7 天后原账号自动失去访问权。看交接步骤

能不能只用报价，不用其他模块？

可以。基础版就是找样加报价，其他模块可以关掉不显示。后面想开再开，数据不会丢。看套餐

一个公司多个门店 / 多个主体怎么办？

每个主体开一个独立公司空间，数据完全隔离；你在老板视角可以切换查看汇总。这类需求走定制版，先做一次需求确认。联系我们
