打印与单证

打印是纺织贸易里最容易出问题的一环：纸不一样、机器不一样、字段经常缺。这一页按「装、配、打、救」四步写。

装打印代理

打印代理随桌面版一起安装，不需要单独下载。装好后打开「设置 → 打印」，代理会自动找局域网里的打印机。

  1. 装桌面版（下载页，内测期间登记后发放）。
  2. 打开「设置 → 打印」，点「扫描打印机」，选中你的机型。
  3. 打一张测试页，确认走纸位置与浓度。

代理只在你的电脑上接收打印任务，单据内容不上传到我们服务器再下发，避免网络抖动导致打一半。

支持哪些机器

类型协议 / 机型用于
标签机Zebra（ZPL）、TSC（TSPL）、佳博、立象箱唛、吊牌、物料标签
针式打印机爱普生 LQ 系列、映美、富士通发货单、对账单（多联）
A4 激光 / 喷墨系统驱动支持的任意机型报价单、合同附件
小票机ESC/POS拣货单、交接单

你的机型不在表里也能试：先在系统里装好驱动，用 A4 或小票方式打；打出来位置不对，把型号和一张照片发给我们，我们加适配。

模板与字段

系统自带一套默认模板，覆盖箱唛、发货单、拣货单、报价单、对账单。字段取自单据本身，不会出现「模板里有但数据没有」的空格：缺字段会在打印前预检并列出。

  • 公司抬头、银行信息、条款：在「组织与设置 → 打印抬头」里改一次，所有模板生效。
  • 一单一码：每张单有二维码，扫码可回到对应单据，也能用于扫码重打。
  • 自定义模板：定制版可改版式，普通版可以调字号与边距。

打印队列与重打

所有打印都进队列，能看到「已发送 / 已打印 / 失败」。失败的任务可以一键重试，不会重复出纸（同一个单据、同一个版本、同一份数重复点击会被合并）。

客户说没收到纸质单？在单据详情点「重打」，选份数即可；每张纸的打印记录都会写进审计，谁在什么时候重打了什么，一查就知道。

打不出来怎么排查

  • 任务一直「已发送」：代理没连上打印机。检查 USB / 网络、机器是否休眠，然后在设置里重新扫描。
  • 打出来是乱码：协议选错。标签机型号是 TSPL 却选了 ZPL，改回来即可。
  • 位置偏移：在打印机设置里做一次测纸 / 校准，再在代理里调边距。
  • 缺字段：单据本身没填，先补数据再打。预检会告诉你缺哪一个。
  • 针式打印机多联不清楚：调浓度与击打力度，或换复写纸；这不是软件问题。

还搞不定就把机型、连接方式（USB / 网口）、一张打废的纸拍给我们。
